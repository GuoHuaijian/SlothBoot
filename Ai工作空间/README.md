## 文件命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 每日改造计划 | `DayXX-改造计划.md` | `Day01-改造计划.md` |
| 每日验收文档 | `DayXX-验收文档.md` | `Day01-验收文档.md` |
| 阶段总结 | `阶段X总结-主题.md` | `阶段一总结-规范先行.md` |
| 设计决策 | `ADR-XXX-标题.md` | `ADR-001-日志体系方案选择.md` |
| 风险记录 | `RISK-XXX-标题.md` | `RISK-001-配置元数据拆分影响.md` |
| 规范文档 | `规范名称规范.md` | `日志规范.md` |

---

## 使用方式

1. **每日开始前**：查阅 `08-每日升级计划/DayXX-改造计划.md`
2. **执行改造**：按照计划中的步骤执行
3. **每日结束后**：执行验收，填写 `09-每日验收文档/DayXX-验收文档.md`
4. **每阶段结束**：填写 `10-阶段总结/阶段X总结-主题.md`
5. **遇到决策**：填写 `12-决策记录/ADR-XXX-标题.md`
6. **发现风险**：填写 `12-决策记录/RISK-XXX-标题.md`
